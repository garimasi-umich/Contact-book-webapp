# Contact Book

A simple single-page contact book built with React and Vite.

**Live site:** https://garimasi-umich.github.io/Contact-book-webapp/

## Features
- Add a contact (name, email, phone) with form validation
- List all contacts
- Search/filter by name or email
- Delete a contact
- Empty state and "no matches" messages
